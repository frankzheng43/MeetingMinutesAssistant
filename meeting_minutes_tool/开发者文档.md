# 会议纪要助手 - 开发者文档

## 项目概述

会议纪要助手是一个桌面工具，用于自动处理 PDF 格式的会议纪要文件。它通过 OCR 识别 PDF 内容，调用 DeepSeek API 提取结构化信息，最终写入 Excel 文件。

支持三种会议类型：**党委会**、**董事会**、**总经办**。

## 技术栈

| 组件 | 技术 |
|------|------|
| 界面 | Python tkinter |
| PDF 转图片 | PyMuPDF (fitz) |
| OCR | 百度 OCR API |
| LLM | DeepSeek API |
| Excel | openpyxl |
| 文件监控 | watchdog |
| 打包 | PyInstaller |

## 项目结构

## 模块说明

### main.py - 主程序入口

提供 tkinter 图形界面，包含：
- 配置输入（监听文件夹、输出目录、API 密钥等）
- 保存/加载配置（config.json）
- 启动/停止监控服务
- 日志显示

关键类：
- `Application`：主应用类，管理界面和监控服务生命周期
- `TextHandler`：自定义 logging 处理器，将日志输出到 GUI 文本框

### watcher.py - 文件监控与核心处理

核心处理模块，包含：

**文件扫描与重命名：**
- `rename_all_pdfs()`：启动时扫描所有 PDF，统一括号格式（`【】[]（）()` → `〔〕`）
- `scan_pdf_files()`：扫描 PDF 文件并提取元信息（会议类型、年份、修改时间）

**扫描记录管理：**
- `load_scan_record()` / `save_scan_record()`：通过 `scan_record.json` 记录已处理的文件
- 启动时对比当前文件列表和上次记录，识别新增/修改/删除的文件

**PDF 处理流程（process_single_pdf）：**
1. PDF 转图片（PyMuPDF，300 DPI）
2. 百度 OCR 逐页识别
3. DeepSeek API 提取结构化数据
4. 写入 Excel（带重试机制）

**文件监控：**
- `MonitorHandler`：watchdog 事件处理器，检测 PDF 创建事件
- `WatcherService`：管理 Observer 和工作线程的生命周期
- `worker_loop`：工作线程主循环，从队列获取任务并处理

**目录结构约定：**
```
监听目录/
├── 2026/
│   ├── 党委会/
│   │   ├── 党委会〔2026〕1号.pdf
│   │   └── 党委会〔2026〕2号.pdf
│   ├── 董事会/
│   │   └── 董事会〔2026〕1号.pdf
│   └── 总经办/
│       └── 总经办〔2026〕1号.pdf
├── 2025/
│   └── ...
├── scan_record.json    # 扫描记录（自动生成）
└── _temp_images/       # 临时图片（自动生成，用完即删）
```

### ocr_utils.py - 百度 OCR 封装

- `BaiduOCR` 类：封装百度 OCR API 调用
- 使用 AK/SK 获取 access_token
- 支持高精度模式（`accurate`）

### llm_utils.py - DeepSeek API 封装

**会议类型检测：**
- `detect_meeting_type()`：根据文件名关键词判断会议类型
- `get_system_prompt()`：返回对应类型的系统提示词

**三种提示词模板：**
- `SYSTEM_PROMPT_PARTY`：党委会 - 提取议定事项、传达学习等
- `SYSTEM_PROMPT_BOARD`：董事会 - 提取议案、投票结果等
- `SYSTEM_PROMPT_GM`：总经办 - 提取督查落实、研究事项等

**纪要编号提取：**
- `extract_record_number_from_filename()`：优先从文件名正则提取（`党委会〔2026〕4号`）
- 失败则由 AI 从内容提取

**印发时间提取：**
- `extract_publish_date_from_text()`：正则匹配（党委会：`XXXX年XX月XX日印发`，董事会/总经办：`XXXX年XX月XX日`）
- `extract_publish_date_via_ai()`：正则失败时 AI 兜底

**主函数：**
- `extract_minutes()`：调用 DeepSeek API，返回结构化 JSON

### excel_utils.py - Excel 读写

**文件命名：**
- 文件名带时间戳：`会议纪要汇总_20260514_144500.xlsx`
- 三个 Sheet：党委会、董事会、总经办

**备份恢复：**
- `backup_excel()`：每次保存前备份到 `_excel_backup/` 目录
- `restore_from_backup()`：Excel 被删后从最近的备份恢复

**数据操作：**
- `append_records()`：追加数据并排序
- `delete_records_by_source()`：按来源文件删除记录
- `_sort_and_rewrite()`：按年份和纪要号从小到大排序

## 数据流

```
PDF 文件创建/新增
    ↓
rename_all_pdfs() - 统一括号格式
    ↓
pdf_to_images() - PyMuPDF 转图片 (300 DPI)
    ↓
BaiduOCR.recognize() - 逐页 OCR
    ↓
extract_minutes() - DeepSeek API 提取
    ├── 纪要编号（优先文件名正则）
    ├── 会议信息（日期、主持人）
    ├── 议题列表（标题 + 内容）
    └── 印发时间（优先正则匹配）
    ↓
append_records() - 写入 Excel
    ├── 追加到对应 Sheet
    ├── 按年份+纪要号排序
    └── 备份旧文件
    ↓
save_scan_record() - 更新扫描记录
```

## 打包说明

使用 PyInstaller 打包为单文件 exe：

```bash
py -m PyInstaller --onefile --windowed --name "MeetingMinutesAssistant" ^
  --hidden-import=watchdog --hidden-import=watchdog.events ^
  --hidden-import=fitz --hidden-import=requests ^
  --hidden-import=openpyxl --hidden-import=PIL ^
  --hidden-import=PIL._imagingtk --hidden-import=PIL.Image ^
  --hidden-import=ocr_utils --hidden-import=llm_utils ^
  --hidden-import=excel_utils --hidden-import=watcher ^
  --distpath "dist" --workpath "build" --specpath "." ^
  "meeting_minutes_tool/main.py"
```

## 扫描记录

`scan_record.json` 保存在监听目录下，记录每个文件的相对路径、修改时间和类型：

```json
{
  "2026\\党委会\\党委会〔2026〕4号.pdf": {
    "mtime": 1744567890.123,
    "meeting_type": "党委会",
    "year": "2026"
  }
}
```

## 错误处理

- **Excel 被占用**：自动重试 5 次，间隔 2 秒
- **Excel 被删除**：从 `_excel_backup/` 目录恢复最近的备份
- **同名文件替换**：检测 mtime 变化，先删旧记录再重新处理
- **API 调用失败**：记录错误日志，文件保留在原位置等待下次处理
