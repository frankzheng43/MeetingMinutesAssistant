# 会议纪要助手 - 用户文档

## 软件简介

会议纪要助手是一个桌面工具，可以自动识别 PDF 格式的会议纪要文件，提取其中的结构化信息（纪要编号、会议日期、主持人、议题等），并汇总到 Excel 文件中。

支持三种会议类型：
- **党委会** - 提取议定事项、传达学习等内容
- **董事会** - 提取议案、投票结果等内容
- **总经办** - 提取督查落实、研究事项等内容

## 准备工作

### 1. 申请百度 OCR API

1. 访问 [百度智能云](https://console.bce.baidu.com/) 并登录
2. 搜索"文字识别"，创建应用
3. 获取 **API Key (AK)** 和 **Secret Key (SK)**

### 2. 申请 DeepSeek API

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 并注册
2. 创建 API Key，充值（费用很低，处理一份文件约几分钱）

### 3. 目录结构要求

监听文件夹建议按以下结构组织：

```
D:\会议纪要\          ← 监听文件夹
├── 2026\             ← 年份文件夹
│   ├── 党委会\       ← 会议类型文件夹
│   │   ├── 党委会〔2026〕1号.pdf
│   │   └── 党委会〔2026〕2号.pdf
│   ├── 董事会\
│   │   └── 董事会〔2026〕1号.pdf
│   └── 总经办\
│       └── 总经办〔2026〕1号.pdf
├── 2025\
│   └── ...
```

> **注意**：文件名中的括号会自动统一为 `〔〕` 格式，如 `党委会【2026】4号` 会自动改为 `党委会〔2026〕4号`。

## 使用步骤

### 第一步：启动软件

双击 `MeetingMinutesAssistant.exe` 启动，界面如下：

![界面布局说明]

### 第二步：填写配置

| 配置项 | 说明 |
|--------|------|
| 监听文件夹 | PDF 文件所在的目录（建议按年份/会议类型组织） |
| 输出目录 | Excel 文件的保存位置 |
| 百度 OCR AK | 百度智能云申请的 API Key |
| 百度 OCR SK | 百度智能云申请的 Secret Key |
| DeepSeek Key | DeepSeek 开放平台申请的 API Key |

### 第三步：保存配置

点击 **"保存配置"** 按钮，配置会自动保存到 `config.json` 文件中，下次启动自动加载。

### 第四步：开始监听

点击 **"开始监听"** 按钮，软件会：
1. **全量扫描** - 遍历监听目录下所有 PDF 文件
2. **对比记录** - 只处理新增或修改过的文件
3. **自动处理** - OCR 识别 → AI 提取 → 写入 Excel

### 第五步：查看结果

处理完成后，在输出目录会生成 Excel 文件，文件名带时间戳，如：
```
会议纪要汇总_20260514_144500.xlsx
```

Excel 文件包含三个 Sheet：
- **党委会** - 党委会会议纪要
- **董事会** - 董事会决议
- **总经办** - 总经理办公会议纪要

每个 Sheet 的表头：
| 纪要编号 | 会议日期 | 主持人 | 年份 | 议题序号 | 议题标题 | 议题详细内容 | 印发时间 | 来源文件 |

数据按 **年份** 和 **纪要号** 从小到大自动排序。

## 功能说明

### 实时监控

启动监听后，往监听目录中放入新的 PDF 文件，软件会自动检测并处理，无需手动操作。

### 文件重命名

文件名中的括号会自动统一为 `〔〕` 格式：
- `【】` → `〔〕`
- `[]` → `〔〕`
- `（）` → `〔〕`

### 同名文件替换

如果某个 PDF 文件被同名文件替换（内容更新），软件会自动检测到修改时间变化，先删除旧的 Excel 记录，再重新处理新文件。

### Excel 备份

每次写入 Excel 时，会自动备份到 `_excel_backup/` 目录。如果 Excel 文件被误删，下次启动时会自动从最近的备份恢复。

### 停止监听

点击 **"停止监听"** 按钮即可停止文件监控。

## 常见问题

### Q: 软件启动后闪退怎么办？

A: 检查 `config.json` 配置文件是否完整，确保所有 API 密钥都已填写。

### Q: Excel 文件被占用无法写入？

A: 关闭正在打开的 Excel 文件，软件会自动重试 5 次。

### Q: 处理速度慢？

A: 每个文件需要经过 OCR 识别和 AI 提取两个步骤，处理时间取决于文件页数和 API 响应速度。一般每份文件约 1-3 分钟。

### Q: 如何重新处理某个文件？

A: 删除 `scan_record.json` 文件（在监听目录下），然后重新启动软件即可全部重新处理。

### Q: Excel 文件被误删了？

A: 软件启动时会自动检查 Excel 是否存在，如果不存在会从 `_excel_backup/` 目录恢复最近的备份。如果备份也没有，则需要重新处理所有文件。

### Q: 如何查看处理日志？

A: 软件界面右侧的日志区域会实时显示处理进度。日志也会输出到控制台（如果有）。

## 隐私声明

**请务必在使用前阅读以下内容：**

本软件在处理会议纪要文件时，会将 PDF 内容通过以下途径传输到第三方服务：

1. **百度 OCR API** - PDF 转图片后，图片数据会发送到百度服务器进行文字识别
2. **DeepSeek API** - OCR 识别出的文字内容会发送到 DeepSeek 服务器进行 AI 提取

**这意味着：**
- 您的会议纪要内容（包括议题、决议等敏感信息）会经过第三方服务器
- 请确保您所在单位允许将此类信息发送到外部 API 服务
- 如涉及国家秘密、商业秘密或个人隐私，**请勿使用本软件处理相关文件**
- 建议在使用前咨询本单位信息安全部门

**数据流向说明：**
```
PDF 文件 → 百度 OCR（云端识别）→ DeepSeek API（AI 提取）→ 本地 Excel
          ↑                        ↑
      数据经第三方服务器      数据经第三方服务器
```

**本软件不存储您的数据：**
- 所有处理结果仅保存在您指定的本地 Excel 文件中
- 临时图片在处理完成后自动删除
- 不会将数据用于任何其他目的

## 注意事项

1. **不要修改 `scan_record.json`** - 这是软件自动生成的扫描记录文件
2. **不要删除 `_excel_backup/` 目录** - 用于 Excel 备份恢复
3. **PDF 文件名建议规范命名** - 如 `党委会〔2026〕4号.pdf`，便于纪要编号提取
4. **API 密钥请妥善保管** - 配置文件 `config.json` 中保存了所有密钥
5. **DeepSeek API 需要充值** - 免费额度有限，请提前充值
